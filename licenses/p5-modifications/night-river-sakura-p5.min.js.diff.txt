Modification to p5.js v1.6.0 (LGPL-2.1), as shipped in app/art/night-river/sakura/p5.min.js

Original: npm package p5@1.6.0, file lib/p5.min.js.
Changes:
  1. A one-line comment is added at the top of the file describing the change.
  2. In p5.Renderer2D's constructor (one place):
       before:  this.drawingContext=this.canvas.getContext("2d"),this._pInst
       after:   this.drawingContext=this.canvas.getContext("2d",{willReadFrequently:!r}),this._pInst
     (r is isMainCanvas: offscreen p5.Graphics get the willReadFrequently hint.)

Purpose: the Sakura scene reads its offscreen graphics back every frame; the hint keeps those canvases
on the CPU so the reads are fast. Nothing else differs. The complete source of p5.js 1.6.0 is in the npm
package p5@1.6.0 (lib/p5.js) and at https://github.com/processing/p5.js/tree/v1.6.0.
